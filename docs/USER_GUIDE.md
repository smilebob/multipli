## Installation & Launch

Multipli is packaged for multiple distributions and platforms:
- **Debian / Ubuntu package (`.deb`)**: Double-click the downloaded file or run `sudo apt install ./multipli_1.0.0_amd64.deb`.
- **Flatpak (`.flatpak`)**: `flatpak install org.gnome.Multipli.flatpak`
- **macOS (`.dmg`)**: Open the `.dmg` file and drag `Multipli.app` into your *Applications* folder.

Launch the game from your GNOME app drawer or run `multipli` in a terminal.

## Profile Management

Multipli supports multiple local profiles so that siblings or classmates can track their progress independently.

### Creating a Profile
1. Click the profile selector at the top-left of the header bar.
2. Select **"New Profile"** (or the `+` button).
3. Enter the child's name, choose an avatar (animals, adventurers, space explorers).
4. Set the initial starting level (Grade 2 to Grade 5 / CE1 to CM2). This calibrates the starting difficulty and recommended tables.
5. Save your changes.

### Editing or Deleting a Profile
- In the profile dropdown, click the pencil icon next to an existing profile to update their avatar, name, or starting level.
- You can reset an individual player's progress without deleting their profile.

## Game Modes

Switch between modes using the bottom navigation view switcher.

### 1. Galactic Adventure
Progress through interplanetary worlds representing difficulty tiers:
- **World 1 (Earth / Beginner)**: Tables 1, 2, 10.
- **World 2 (Moon / Explorer)**: Tables 3, 4, 5.
- **World 3 (Mars / Adventurer)**: Tables 6, 7.
- **World 4 (Jupiter / Star Master)**: Tables 8, 9.
- **World 5 (Cosmic Challenge)**: Full 1-10 mix and speed challenges.

Each level awards stars and unlocks achievement trophies.

### 2. Training Dojo
Focus on specific tables at a comfortable, stress-free pace:
- Select which multiplication tables to practice.
- Choose between **Multiple Choice (QCM)** (4 options) or **Keypad Input**.
- No countdown timer: ideal for understanding the additive structure of multiplication.

### 3. 60s Speed Run
Test calculation reflexes and speed under friendly pressure:
- 60 seconds to answer as many questions as possible.
- High scores are saved locally to track improvement over time.

### 4. Interactive Pythagoras Table
A visual grid that helps children grasp commutativity ($a \times b = b \times a$):
- Hover or click on cells to highlight intersecting rows and columns.
- Color-coded mastery indicates mastered facts vs. facts that need more practice.

## Input Methods & Keyboard Shortcuts

Optimized for desktop and laptop keyboards:
- **Multiple Choice Mode**: Click answers on screen or press keyboard keys `1`, `2`, `3`, or `4`.
- **Keypad Mode**:
  - Enter numbers via the on-screen keypad or physical number keys.
  - Press `Return` / `KP_Enter` to validate the answer.
  - Press `Backspace` to clear the last digit entered.

## Settings & Customization

Open preferences via the primary menu (three dots in top-right corner):
- **Language**: English, French, Spanish, German (switches live without restarting).
- **Sound Effects**: Toggle audio on/off and adjust volume.
- **Visual Theme**: Seamlessly adapts to GNOME system light or dark preferences.
- **License & Open Source**: Direct access to Apache 2.0 license information and GitHub repository.
